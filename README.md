Lines-of-code statistics exclude files under common dependency directories,
including `vendor`, `node_modules`, `lib`, and `third_party`. Set the optional
`EXCLUDED_PATHS` environment variable to a comma-separated list of additional
directory names, repository-relative paths, or glob patterns to exclude.

The language chart scans each accessible repository's default-branch Git tree
and totals the byte sizes of files with recognized extensions. This extension
mapping can differ from GitHub Linguist; files with unrecognized or no
extension are omitted. Library directories and `EXCLUDED_PATHS` are excluded
from the chart as well. If GitHub reports a truncated tree or a scan otherwise
fails, image generation stops with an error rather than showing partial
language totals.

The scan includes public and private repositories accessible to the
`ACCESS_TOKEN` configured in the workflow. That token needs read access to
repository metadata and contents; repositories the token cannot read are not
included.
